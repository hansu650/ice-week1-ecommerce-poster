# Simple Upload Rules / 简易上传规则

Each team member may submit one ZIP package. The team leader will review and merge it into `main`.

每位组员直接提交一个ZIP素材包，由组长检查后合并到 `main`。

## Upload steps / 上传步骤

1. Use your own GitHub account.
2. Create a branch named `upload/<github-username>`.
3. Upload your ZIP file to `materials/<github-username>/`.
4. Name it `<github-username>-week1-materials.zip`.
5. Open a Pull Request titled `[ZIP] <github-username> Week 1 materials`.
6. Leave the Pull Request for the team leader to merge.

## ZIP contents / ZIP内容

The package may contain the papers or source links, data, figures, notes, and code already collected in your conversation. No additional restructuring is required.

素材包可以直接包含此前对话整理好的论文或来源链接、数据、图片、笔记和代码，不要求重新复杂整理。

## Essential public-repository safety / 公开仓库基本要求

Before uploading, remove:

- passwords, tokens, API keys, cookies, and private configuration;
- student IDs, phone numbers, and unredacted private chats;
- copyrighted files that cannot legally be redistributed.

Do not invent sources or data. If a file is too large for GitHub, provide a download link instead.

不要把组长账号或密码发给任何人。默认由组长合并，组员不要直接改 `main`。
