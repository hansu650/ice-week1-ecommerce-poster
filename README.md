# ICE Week 1: E-commerce Trends Poster

This repository records the evidence, source material, data processing, visualisations, and poster development for Week 1 of [Industry and Community Engagement](https://moodle.mmu.ac.uk/course/view.php?id=205526).

## Official Week 1 theme

> Investigating the growth and trends of e-commerce in China, and how it impacts the global industry.

## Working poster direction

**From Domestic Scale to Global Reach: How China's Cross-border E-commerce Is Reshaping Global Retail**

The working title may be refined after the team reviews the available papers, datasets, and figures.

## Purpose

The repository is intended to provide a transparent evidence chain:

**source → data → processing code → figure → poster → process evidence**

It will contain:

- source links and properly attributed references;
- raw or processed datasets where redistribution is permitted;
- reproducible chart-generation code;
- redrawn or adapted figures with clear attribution;
- poster drafts and the final high-resolution poster;
- selected, privacy-safe evidence of the team's development process.
